- Python 3.12
- FastAPI
- SQLAlchemy ORM
- SQLite (prototype database)
- Pydantic
- NetworkX
- Pandas
- Scikit-learn
- ReportLab
- Python-dotenv

Project Name:
CrimeLens AI

Create FastAPI routes:

GET /dashboard
Return:
- total crimes
- active investigations
- repeat offenders
- hotspot districts
- recent incidents

GET /hotspots
Return latitude, longitude, district, crime count for heatmap visualization.

GET /network/{offender_id}
Return nodes and edges for NetworkX graph visualization.

GET /offender/{id}
Return complete offender profile with crime history.

POST /chat
Accept natural language questions and return placeholder AI responses for now.

GET /predict
Return predicted hotspot district, crime type, risk score and reasoning.

GET /health
Return backend status.

Create service files for:
- dashboard_service
- hotspot_service
- graph_service
- prediction_service
- ai_service

Generate mock data (50-100 records) automatically on first run.

Enable CORS for React frontend running on localhost:5173.

Create Swagger documentation.

Create requirements.txt.

Create README with setup instructions.

The backend should run successfully using:

uvicorn app.main:app --reload
